A fully atomistic **molecular dynamics simulation of graphene kirigami under uniaxial tension**, using LAMMPS. A single-layer graphene sheet is cut with a brick-wall pattern of parallel slits, relaxed, equilibrated at 300 K, and stretched to 100 % nominal strain between two rigid grips. The cut strips rotate out of plane at narrow hinges, which lets the sheet stretch far beyond the strain that pristine graphene can carry.

The simulation captures the low-stress **out-of-plane pop-up** of the strips, **thermal rippling** of the free sheet, **stiffening** as the strips align with the load, and **C-C bond breaking at the cut tips**, using the *AIREBO potential (CH.airebo)* with a modified inner cut-off for large strain and fracture. The grip force gives the stress-strain curve, and the per-atom out-of-plane displacement, potential energy, and stress are written for visualization in OVITO.

## Physics

The simulation captures the full tensile response of a kirigami sheet at the atomistic scale:

- Single-layer graphene modeled with the AIREBO reactive potential (REBO + Lennard-Jones + torsion)
- Kirigami geometry generated by a Python script: a graphene lattice with rectangular cuts removed (no external CAD files)
- Brick-wall cut pattern: neighbouring cut rows are offset by half a cell, leaving narrow hinge ligaments
- Dangling atoms with fewer than two neighbours removed automatically; optional hydrogen passivation of all cut edges
- Small random out-of-plane perturbation and 300 K thermal motion break the flat-sheet symmetry, so the strips can buckle
- Rigid grips at both ends moved apart at constant velocity, giving a constant engineering strain rate
- Free atoms start with a linear velocity profile matching the grips, so no shock wave enters the sheet
- Nose-Hoover thermostat on the free atoms only; grips integrated with NVE at prescribed velocity
- Grip reaction force (time-averaged) converted to stress using a graphene thickness of 3.35 Angstrom
- Per-atom out-of-plane displacement, potential energy, and stress for tracking pop-up and bond damage

## Strain Rate Regime

| Regime                        | Strain Rate (1/s)   | This Simulation     |
| ----------------------------- | ------------------- | ------------------- |
| Quasi-static experiments      | < 1                 | No                  |
| High-rate experiments         | 1e2 to 1e4          | No                  |
| Shock loading                 | 1e6 to 1e8          | No                  |
| **Typical MD tensile tests**  | **1e8 to 1e10**     | **Yes (5e9)**       |

MD strain rates are far above experimental rates because of the femtosecond timestep. Check rate sensitivity (for example 1e9 and 1e10) before drawing quantitative conclusions.

## Kirigami Cut Pattern

The sheet is cut with rows of straight slits running along x, perpendicular to the loading direction y. Even rows have interior cuts with half-ligaments at the sheet edges; odd rows are shifted by half a cell, giving edge cuts with a central ligament.

| Parameter      | Script keyword | Default      | Role                                                    |
| -------------- | -------------- | ------------ | ------------------------------------------------------- |
| Cut length     | `CUT_L`        | 60 Angstrom  | Longer cuts give softer, more stretchable sheets        |
| Hinge ligament | `LIG`          | 15 Angstrom  | Narrow hinges rotate easily but fail earlier            |
| Cut width      | `CUT_W`        | 5 Angstrom   | Removes about two atom rows                             |
| Row pitch      | `ROW`          | 25 Angstrom  | Width of each strip between cut rows                    |
| Cells across   | `N_COLS`       | 2            | Number of cut periods across the width                  |
| Cut rows       | `N_ROWS`       | 8            | Number of cut rows along the loading direction          |
| Grip length    | `GRIP`         | 15 Angstrom  | Uncut region at each end held by the grips              |
| Edge hydrogen  | `PASSIVATE_H`  | False        | True adds H (C-H 1.09 Angstrom) to every edge carbon    |

The geometry builder prints the number of C and H atoms and the sheet size at startup.

## Geometry

```
Graphene sheet (units: Angstrom), top view:

y = 224.9 +------------------------------------------+  <- sheet top
          |///////// TOP GRIP (15 Ang) //////////////|  moves +v/2 in y
y = 209.9 +------------------------------------------+
          |  ======   ==============   ======        |  <- odd row: edge cuts
          |      ==============   ==============     |  <- even row: interior cuts
          |  ======   ==============   ======        |
          |      ==============   ==============     |  8 cut rows, pitch 25 Ang
          |  ======   ==============   ======        |  free atoms: NVT at 300 K
          |      ==============   ==============     |
          |  ======   ==============   ======        |
          |      ==============   ==============     |
y =  15.0 +------------------------------------------+
          |//////// BOTTOM GRIP (15 Ang) ////////////|  moves -v/2 in y
y =   0.0 +------------------------------------------+  <- sheet bottom
          x = 0                               x = 146.4

x: zigzag direction (cuts run along x)
y: armchair direction (loading direction)
z: out of plane (free, the strips pop up along z)
Boundary: shrink-wrapped (s s s), no periodic images
```

- **Sheet**: single-layer graphene, 146.4 x 224.9 Angstrom (14.6 x 22.5 nm)
- **C-C bond length**: 1.397 Angstrom (AIREBO equilibrium)
- **Cuts**: 60 Angstrom long, 5 Angstrom wide, 15 Angstrom hinge ligaments, 2 x 8 cells
- **Grips**: atoms within 15 Angstrom of each end, force zeroed, prescribed velocity
- **Gauge length**: about 195.6 Angstrom, measured between the grips after relaxation
- **Stretching velocity**: 0.98 Angstrom/ps total (each grip 0.49 Angstrom/ps, about 49 m/s)

### Default System Size

| Component      | Atom type | Atoms      |
| -------------- | --------- | ---------- |
| Bottom grip    | 1 (C)     | 914        |
| Top grip       | 1 (C)     | 914        |
| Free sheet     | 1 (C)     | 9,312      |
| Edge hydrogen  | 2 (H)     | 0 (off)    |
| **Total**      | -         | **11,140** |

## Simulation Phases

| Phase            | Run Steps   | Simulated Time | Description                                                       |
| ---------------- | ----------- | -------------- | ----------------------------------------------------------------- |
| Geometry         | -           | -              | Python builds the cut sheet and writes `graphene_kirigami.data`   |
| Minimization     | up to 5,000 | -              | Conjugate gradient with grips held; cut edges relax               |
| Equilibration    | 20,000      | 20 ps          | Free atoms thermalized at 300 K (NVT); grips at rest              |
| Stretching       | 200,000     | 200 ps         | Grips move apart at 5e9 1/s from 0 to 100 % strain                |
| **Total MD**     | **220,000** | **220 ps**     | -                                                                 |

The timestep is reset to 0 at the start of the stretching phase, and the dump file starts there.

## Key Event Timeline

Strain increases linearly with time during stretching (1 % per 2,000 steps, which is one dump frame). The strains below are from the verification run on a smaller sheet; use `stress_strain.txt` for the actual values of your run.

| Event                                     | Nominal strain | Stretch step | Dump frame |
| ----------------------------------------- | -------------- | ------------ | ---------- |
| Stretching starts, thermal ripples only   | 0 %            | 0            | 0          |
| Strips start rotating out of plane        | ~2 to 5 %      | ~4,000-10,000| 2 to 5     |
| Low-stress pop-up regime                  | up to ~30 %    | ~60,000      | 30         |
| Strips align with the load, stiffening    | ~30 to 38 %    | ~60,000-76,000 | 30 to 38 |
| First C-C bonds break at cut tips         | ~38 %          | ~76,000      | 38         |
| End of run                                | 100 %          | 200,000      | 100        |

Whether the sheet fails early or keeps stretching depends on the hinge width, cut length, edge passivation, temperature, and strain rate.

| Thickness for stress  | t      | 3.35           | Angstrom |
| Temperature           | T      | 300            | K        |

### Loading

| Parameter        | Symbol | Value  | Unit         |
| ---------------- | ------ | ------ | ------------ |
| Strain rate      | e_dot  | 5e9    | 1/s          |
| Final strain     | e_max  | 1.0    | -            |
| Timestep         | dt     | 0.001  | ps           |
| Grip velocity    | v/2    | 0.49   | Angstrom/ps  |

### Interatomic Potential

| Parameter       | Value                                                  |
| --------------- | ------------------------------------------------------ |
| Potential file  | CH.airebo-mod (created from CH.airebo on first run)    |
| Potential style | `airebo 3.0 1 1` (REBO + LJ with 3 sigma cut-off + torsion) |
| Type 1          | C                                                      |
| Type 2          | H (edge passivation, optional)                         |
| pair_coeff      | `* * CH.airebo-mod C H`                                |

`CH.airebo-mod` is the official `CH.airebo` with a single change on line 7: the inner C-C switching radius `rcmin_CC` is raised from 1.7 to 1.95 Angstrom. The original switching function makes C-C bonds artificially stiff just before they break, which gives a non-physical stress spike at fracture. Run with `-var POT CH.airebo` to use the original file.

Do not confuse `CH.airebo-mod` with `CH.airebo-m`, which ships with LAMMPS and is a different potential (AIREBO-M, for `pair_style airebo/morse`).

### Boundary Conditions

| Group        | Condition                         | Description                                     |
| ------------ | --------------------------------- | ----------------------------------------------- |
| Bottom grip  | `setforce 0 0 0`, vy = -v/2, NVE  | Rigid grip moving down                          |
| Top grip     | `setforce 0 0 0`, vy = +v/2, NVE  | Rigid grip moving up                            |
| Free sheet   | NVT at 300 K                      | Full dynamics, pop-up and fracture              |
| All directions | Shrink-wrapped (s)              | No periodic images, sheet free to buckle in z   |

## Governing Equations

### Kirigami Geometry

```
cell = CUT_L + LIG
row r centre:  y_r = GRIP + (r + 0.5) * ROW
row shift:     s_r = 0 (even r),  cell/2 (odd r)

delete atom if  x0 < x < x0 + CUT_L   and   |y - y_r| < CUT_W/2
where x0 = c * cell + s_r + LIG/2  for every cell c
```

### Strain and Grip Velocity

```
L0      = y_min(top grip) - y_max(bottom grip)      after relaxation
strain  = (L(t) - L0) / L0
v       = e_dot * L0                                 total separation velocity
          top grip +v/2, bottom grip -v/2
free atoms initialised with  vy(y) linear from -v/2 to +v/2
N_steps = e_max / (e_dot * dt)
```

### Force and Stress

```
F_y   = 0.5 * ( F_bottom,y - F_top,y ) * 1.602177     [nN]
        (force the sheet exerts on the grips, from fix setforce)

sigma = F_y / (W0 * t) * 100                          [GPa]

where:
  W0 = sheet width (Angstrom)
  t  = 3.35 Angstrom (graphene interlayer spacing)
  1 eV/Angstrom = 1.602177 nN
  1 nN/Angstrom^2 = 100 GPa
```

Force and stress are time-averaged over each output interval with `fix ave/time` (10 samples), because the instantaneous MD force is noisy.

### AIREBO Potential Energy

```
E = 1/2 * sum_i sum_{j != i} [ E_REBO_ij + E_LJ_ij + sum_{k != i,j} sum_{l != i,j,k} E_tors_kijl ]

E_REBO_ij = V_R(r_ij) - b_ij * V_A(r_ij)          (bond order b_ij)

Switching function between rcmin and rcmax:
S(r) = 0.5 * [ 1 + cos( pi * (r - rcmin) / (rcmax - rcmin) ) ]
rcmin_CC = 1.95 Angstrom (modified), rcmax_CC = 2.0 Angstrom
```

### Per-Atom Stress (LAMMPS units: bar * Angstrom^3)

```
S_ab,i = -[ m_i * v_ia * v_ib + W_ab,i ]

approximate stress:  sigma_yy,i = S_yy,i / V_atom * 1e-4   [GPa]
V_atom = 2.62 Angstrom^2 * 3.35 Angstrom = 8.78 Angstrom^3
```

### Out-of-Plane Amplitude

```
z_amp = z_max(free atoms) - z_min(free atoms)
u_z,i = z_i(t) - z_i(start of stretching)
```

## Group Definitions

```
bot      <- atoms within 15 Angstrom of the bottom edge (bottom grip)
top      <- atoms within 15 Angstrom of the top edge (top grip)
grips    <- bot + top
mobile   <- all atoms except the grips (free sheet, thermostatted)
```

## How to Run

### Requirements

- LAMMPS (any recent version with the MANYBODY package for `pair_style airebo`): <https://www.lammps.org>
- AIREBO potential file `CH.airebo` (included with LAMMPS in the `potentials/` folder)
- Python 3 with numpy, scipy, and matplotlib
- OpenMPI for parallel runs
- OVITO for trajectory visualization: <https://www.ovito.org>

On Ubuntu or WSL:

```
sudo apt update
sudo apt install -y lammps openmpi-bin python3-numpy python3-scipy python3-matplotlib dos2unix
```

### Step 1: Choose the cut pattern

Edit the parameters at the top of `make_graphene_kirigami.py`:

```
N_COLS   = 2       # unit cells across the width
CUT_L    = 60.0    # cut length (Angstrom)
LIG      = 15.0    # hinge ligament (Angstrom)
CUT_W    = 5.0     # cut width (Angstrom)
ROW      = 25.0    # row pitch (Angstrom)
N_ROWS   = 8       # number of cut rows
GRIP     = 15.0    # grip length at each end (Angstrom)
PASSIVATE_H = False
```

or override them on the command line:

```
python3 make_graphene_kirigami.py N_COLS=3 N_ROWS=10 CUT_L=80
```

### Step 2: Run the simulation

Full pipeline (potential files, geometry, MD, plots):

```
bash run_lammps.sh
```

Or step by step:

```
cp /usr/share/lammps/potentials/CH.airebo .
sed '7s/^1\.7\t/1.95\t/' CH.airebo > CH.airebo-mod
python3 make_graphene_kirigami.py
mpirun -np 14 lmp -in in.kirigami
python3 plot_kirigami.py
```

Parallel with OpenMP threads instead of MPI:

```
lmp -sf omp -pk omp 14 -in in.kirigami
```

Change simulation settings without editing the script:

```
mpirun -np 14 lmp -in in.kirigami -var T 4.2 -var RATE 1e9 -var EMAX 1.5
```

With hydrogen passivation, use a smaller timestep: `-var DT 0.0005`.

If the files were edited or extracted on Windows, convert line endings first: `dos2unix *.sh *.py in.kirigami`.

### Step 3: Visualize in OVITO

1. Open OVITO, then `File > Load File` and select `graphene_kirigami.data` to check the cut pattern
2. Load `dump.kirigami` for the stretching trajectory (all 101 frames load as an animation)
3. In the reader panel, use **Edit column mapping** to rename `c_dsp[3]` to `uz`
4. Add **Create bonds** with a uniform cut-off of 1.9 Angstrom; broken bonds disappear during stretching
5. Add **Color Coding** on `uz` (Rainbow, fixed range -15 to 15 Angstrom) to follow the pop-up
6. Untick the **Particles** visual element to show only the coloured bond network
7. Set the vertical axis to Y (`Application Settings > Viewports`) and use **Adjust View** with direction about (0.80, 0.23, -0.56)
8. Colour by `c_pe` to locate damaged regions near the cut tips
9. Plot `stress_strain.txt` (or run `plot_kirigami.py`) to see the stress-strain curve

Each dump frame is 1 % strain (frame 20 = 20 %, frame 50 = 50 %).

## What to Look for in Results

### Thermal Rippling

Before and at the start of stretching, the free sheet shows random out-of-plane ripples of a few Angstrom at 300 K. Rerun at 4.2 K to see the difference.

### Out-of-Plane Pop-Up

At small strain the stress stays low while the strips rotate out of plane at the hinges. `z_amplitude` in `stress_strain.txt` grows from a few Angstrom to several nanometres. Neighbouring strips tilt in opposite directions.

### Stiffening

Once the strips are nearly aligned with the load, further extension stretches the C-C bonds directly, and the stress rises steeply.

### Fracture at the Cut Tips

The hinge ligaments carry the highest stress. Bonds at the cut tips break first, the stress drops, and cracks run across the ligaments. In OVITO, missing bonds and high `c_pe` mark the damage.

### Effect of the Cut Pattern

Longer cuts and narrower ligaments give lower stiffness and larger stretchability but lower strength. Compare stress-strain curves for different `CUT_L`, `LIG`, and `ROW` values, and against a pristine sheet (set `CUT_L=0`).

## Common Errors and Fixes

| Error or symptom                                   | Cause                                                         | Fix                                                                          |
| -------------------------------------------------- | ------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| `Cannot open AIREBO potential file CH.airebo-mod`  | Potential file not created                                    | Run `bash run_lammps.sh`, or the two commands in Step 2                      |
| `MPI_ABORT` with no message at `pair_coeff`        | Extra lines added to the top of the potential file            | Keep the original header; only change line 7                                 |
| Wrong stress values or strange bonding             | `CH.airebo-m` (AIREBO-M, Morse) used instead of `CH.airebo-mod` | Use `CH.airebo-mod` or `CH.airebo` with `pair_style airebo`                |
| Temperature spikes to thousands of K at the start  | Strain rate so high that the grips move near the speed of sound | Use 1e10 1/s or lower                                                      |
| `$'\r': command not found`                         | Windows line endings                                          | `dos2unix *.sh *.py in.kirigami`                                             |
| `can't open file make_graphene_kirigami.py`        | Zip extracted into a nested folder                            | `cd` into the inner folder that contains the scripts                         |
| `Cannot use neighbor bins - box size << cutoff`    | Perfectly flat sheet in a shrink-wrapped box                  | Keep the `displace_atoms` line before the minimization                       |
| `not enough slots` from mpirun                     | Fewer cores than `-np`                                        | Lower `-np` to the value of `nproc`, or add `--oversubscribe`                |
| `WARNING: Proc sub-domain size < neighbor skin`    | Thin sheet split across many processors                       | Harmless; can be ignored                                                     |
| `WARNING: Temperature for fix modify is not for group all` | Thermostat uses the free-atom temperature on purpose  | Harmless; intended                                                           |

## Extending the Model

| Extension                          | What to change                                                                  |
| ---------------------------------- | ------------------------------------------------------------------------------- |
| Different cut pattern              | Change `CUT_L`, `LIG`, `ROW`, `N_COLS`, `N_ROWS`                                |
| Pristine sheet comparison          | Set `CUT_L=0` in `make_graphene_kirigami.py`                                    |
| Passivated edges                   | `PASSIVATE_H=True` and `-var DT 0.0005`                                         |
| Temperature effects                | `-var T 4.2`, `-var T 600`, ...                                                 |
| Rate sensitivity                   | `-var RATE 1e9`, `-var RATE 1e10`                                               |
| Loading along zigzag               | Swap the lattice orientation in `make_graphene_kirigami.py`                     |
| Other 2D materials                 | MoS2 with Stillinger-Weber, h-BN with Tersoff: change the lattice and pair style |
| Original AIREBO cut-off            | `-var POT CH.airebo`                                                            |
| Rotating-square kirigami           | Replace the slit pattern with crossed cuts in the geometry builder              |
| Continuum comparison               | Compare with a CalculiX shell or solid model of the same cut pattern            |
